# Sistema de Gestión de Refugio de Animales

## Descripción
Proyecto desarrollado en Java aplicando Programación Orientada a Objetos y principios SOLID.

## Funcionalidades
- Registro de animales
- Gestión de adopciones
- Vacunación
- Notificaciones

## Tecnologías
- Java
- IntelliJ IDEA
- GitHub

# Principios SOLID

## S - Single Responsibility Principle
Cada clase tiene una única responsabilidad.

## O - Open/Closed Principle
El sistema puede extenderse creando nuevas clases.

## L - Liskov Substitution Principle
Las subclases pueden reemplazar a la clase padre.

## I - Interface Segregation Principle
Las interfaces fueron separadas según responsabilidades.

## D - Dependency Inversion Principle
Las clases dependen de abstracciones y no de implementaciones concretas.
